# Token Hold'em Avatar Personas

Reusable non-infringing persona and prompt notes for future AI player portraits. These are placeholder concepts only: no image files, external assets, or generated images are included.

## Shared Avatar Rules

- Treat model names as personality seeds, not brand marks.
- No logos, wordmarks, exact mascots, product icons, UI marks, or company-specific costume markings.
- Readability target: face and silhouette must work inside the current 34-42 CSS px avatar square.
- Format target: 512x512 portrait, transparent PNG/WebP with alpha, centered bust or waist-up pose, 5-10% padding.
- Lighting: consistent warm tavern rim light from upper left, green felt bounce from below, simple readable shadows.
- Default emotes: `neutral`, `confident`, `thinking`, `surprised`, `smug`, `worried`, `celebrate`, `defeated`.
